# [Kingdom Hearts Dream Drop Distance](../index.md) - techprm

Location: /game/bin/

This section covers both `techprmp.bin` and `techprm.bin`. Both files contain data for techniques performed by both the player and enemies respectively, including a technique's power percentage and status effects. 

Because of the new Dream Eaters from the 2.8 Collection, enemy technique indexes deviate at 0833. This document tracks the PC offsets.

## File Structure

Both files are structured as shown. 

| Amount | Description                   |
| ------ | ----------------------------- |
| X      | Entries (20 bytes each)       |
| 1      | EOF (CD CD CD CD CD CD CD CD) |

## Entry Structure

| Position	| Type		| Description										|
| --------- | --------- | ------------------------------------------------- |
| 0x00		| int16		|	Index											|
| 0x02		| int16		|	Power (%)										|
| 0x04		| int8		|	Attack Effect									|
| 0x05		| int8		|	Attack Type										|
| 0x06		| int8		|	Status Effect									|
| 0x07		| int8		|	< unknown >										|
| 0x08		| int8		|	Attack Element									|
| 0x09		| int8		|	Status Rate										|
| 0x0A		| int8		|	Target											|
| 0x0B		| int8		|	< unknown > 									|
| 0x0C		| int16		|	Status Effect Duration							|
| 0x0E		| int8	 	|	Can be blocked?									|
| 0x0F		| int8	 	|	< unknown > 									|
| 0x10		| int8    	|	[Reaction Endurance](https://www.khwiki.com/Reaction_Endurance)								|
| 0x11		| int8[3] 	|	BLANK											|

### Status Effects

Status Effects are triggered when Status Rate (0x09) is greater than 0%, and lands within the Status Rate. 

| 0x06	|	Status Effects										|
|-------|-------------------------------------------------------|
|	01	|	Stun												|
|	02	|	Sleep												|
|	04	|	Bind												|
|	08	|	Stop												|
|	10	|	Poison												|
|	20	|	Ignite												|
|	40	|	Confuse												|
|	80	|	Blackout											|
