| Amount | Description                   |
| ------ | ----------------------------- |
| X      | Entries (20 bytes each)       |
| 1      | EOF (CD CD CD CD)             |

## Entry Structure

Each entry is grouped by a category, type, and tier. Some categories may include a header, footer, or dummy entry. Names for command categories and types are based off of KHWiki and game references. 

Slot ownership is not entirely known, but there are reserved values for Sora-only, Riku-only, and all-equippable commands. Each value may correlate to the category or in-game context; further testing is required.

Effects are not entirely known, and its value may be used contextually in-game. For example, Potion (ID 5B) uses 0x0C as an amount of HP to heal, but Cure (ID 39) uses 0x0C as a power percentage. 

| Position | Type    | Description                                        |
| -------- | ------- | -------------------------------------------------- |
| 0x00     | int8    | Category                                           |
| 0x01     | int8    | Type                                               |
| 0x02     | int8    | Tier                                               |
| 0x03     | int8    | Element                                            |
| 0x04     | int8    | Index                                              |
| 0x05     | int8    | Slot Cost                                          |
| 0x06     | int8    | Slot Ownership                                     |
| 0x07     | int8[3] | BLANK                                              |
| 0x0A     | int8    | Reload Time / Slot Inventory                       |
| 0x0B     | int8    | BLANK                                              |
| 0x0C     | int8[2] | Effect 1                                           |
| 0x0E     | int8[2] | Effect 2                                           |
| 0x10     | int8[2] | Effect 3                                           |
| 0x12     | int8[2] | Effect 4                                           |
