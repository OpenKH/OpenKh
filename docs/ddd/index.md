### BIN Files

- [btlparam](file/game-bin/btlparam.md) - Battle Param: Entity stats
- [cmddata](file/game-bin/cmddata.md) - Command Data: Internal specs of commands
- [dropprm](file/game-bin/dropprm.md) - Drop Param: Entity drops
