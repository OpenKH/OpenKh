OPENKH QUICK START FOR LINUX AND STEAM DECK
============================================

Open a terminal in this folder and run:

    sh install-openkh-linux.sh

The installer makes the applications executable and adds OpenKH to the desktop
application menu. On Steam Deck, open Steam in Desktop Mode, select "Add a
Non-Steam Game", and choose OpenKH. You can then return to Game Mode.

Start OpenKH with the launcher. Choose "Open Mod Manager" to install and play
mods. The launcher and Mod Manager support Steam Input, SDL controllers, and the
Steam Deck floating keyboard in text fields.

The Apps folder contains the Mod Manager and its required resources. Keep it
next to the launcher.

Use "Check for Updates" in the launcher footer to check and install the Linux
OpenKH package. Updates are only installed after you confirm them.

Documentation: https://openkh.dev/
